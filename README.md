# Курс по РИП
Репозиторий содержит асинхронный микросервис для выполнения отложенных вычислений в системе управления заявками на умные устройства.  
Проект включает:  
- HTTP-сервис на **Django** с эндпоинтом для запуска расчёта (задержка 5–10 сек)  
- Вычисление метрики по предметной области 
- Взаимодействие с основным бэкендом через HTTP с простой псевдо-авторизацией (фиксированный токен)
